FAQ

Frequently Asked Questions

What is a CSV file? ▼
A CSV (Comma Separated Values) file is a simple format where data is stored in rows and columns — similar to an Excel sheet. You can save any Excel file as CSV using File → Save As → CSV format.
Is my data safe and private? ▼
Yes! Your file is only stored temporarily during processing. Once the cleaning is complete, it is automatically removed from the server. No data is stored or shared with anyone.
What is the maximum file size? ▼
You can upload CSV files up to 10MB in size. This typically supports millions of rows. For larger files, please contact us directly.
What cleaning operations are performed? ▼
Four operations are performed automatically: (1) Remove duplicate rows, (2) Remove empty/null values, (3) Convert column names to lowercase underscore format, (4) Strip extra whitespace from all text fields.
What is the CI/CD pipeline in this project? ▼
When a developer pushes code to GitHub, GitHub Actions automatically runs tests, builds a Docker image, and deploys the latest version to the cloud — with zero manual steps required.
